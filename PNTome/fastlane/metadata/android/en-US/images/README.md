# Store images (user supplied)

No artwork or screenshots are committed. Add the following files here before publishing:

| File | Requirement |
|---|---|
| `icon.png` | 512 x 512 px, PNG, 32-bit, no rounded corners (the store applies the mask) |
| `featureGraphic.png` | 1024 x 500 px, PNG or JPEG, no alpha |
| `phoneScreenshots/1.png`, `2.png`, ... | At least 2 phone screenshots (Google Play accepts 2 to 8); PNG or JPEG, 16:9 or 9:16, each side between 320 and 3840 px |

Capture screenshots from a real device or emulator running a release build. Do not use mock-ups that show features the app does not have.

Check the current limits in the Play Console help before uploading, as they can change.
